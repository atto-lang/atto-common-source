# Conditional Euclidean modulus correction contract

Status: MODEL_PROVED, not compiler-proved. Requires b != 0 and a valid signed remainder r with -|b| < r < |b|. The correction returns r if nonnegative, r+b for a negative remainder and positive divisor, or r-b for a negative remainder and negative divisor. A 65-bit independent reference computes the magnitude without overflowing at signed minimum. The five obligations establish exact correction, nonnegative range below magnitude, identity on nonnegative remainder, exact correction amount, and zero for unit divisors. This is the correction used by the Java StrictIntegerArithmetic.mod helper; other implementations must establish their own correspondence.
