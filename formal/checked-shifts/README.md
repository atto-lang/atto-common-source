# Checked signed-i64 shifts

Based on the checked distance and bit-pattern rules in atto-spec main `language/bitwise-and-stream-operators-v1.md` (reviewed Git blob 1cd08cbae07da5788735b50d3f1f790ad04a9c48). The three operations are left shift, logical right shift, and arithmetic right shift. Counts are exactly 0..63; invalid counts must be denied, never masked. Left shift discards high bits, not checked multiplication overflow.

The model proves that the unsigned 64-bit comparison against 64 is equivalent to the signed interval, that each legal shift agrees with its corresponding widened result, and that zero is the identity. Counterexamples distinguish masking, signed-upper-bound-only admission and arithmetic/logical right confusion. Z3 4.13.3.0 library replay: five UNSAT obligations, three mutation SAT and four reachability SAT. This mathematical contract is not a compiler proof.

Run `python3 verify.py --solver /path/to/z3 --witnesses`. The pinned model requires an exact solver transcript. The optional independent native C (Clang O0/O2), Java and Node BigInt witnesses use the same deterministic 100,792-row corpus and Python unbounded arithmetic oracle. Each passed 60,704 valid triples and 40,088 invalid-count rejections: 403,168 rows across four executions, 728,448 bit-pattern values and 160,352 invalid-count rejections. Actual Atto compiler output, language-level error identity, effect ordering, and guest/actor parity remain independently unverified. These are host-language witnesses, not compiler receipts.
