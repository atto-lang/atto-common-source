# M8 compiler safe-point IR profile v1

**Candidate cross-backend contract, not a declaration of backend parity.** This IR is the narrow next step after the [M7 suspended actor ABI](../contracts/actor-cooperate-safepoint-v1.json). M8 intentionally starts with one separately checked integer accumulator loop in a compiled `.atto` actor; it does not admit general user code, arbitrary `await`, or arbitrary `select`.

A language source loop containing explicit `rt cooperate;` lowers to **ENTRY → LOOP_GUARD → CHECKED_ACCUMULATE_AND_INCREMENT → COOPERATE → LOOP_GUARD**, then DONE. The compiler commits all local slots and the **resume PC** before returning a YIELD. A subsequent slice resumes from the saved PC and never replays a completed addition or index increment. Signed 64-bit overflow must fail instead of wrapping.

**Budget:** each executed safe point charges one reduction. The per-resume budget is 1–65536. A bytecode or native implementation must consume at most the allowed charged reductions and return YIELD if more loop work remains. Time budgets are checked at safe points; uncooperative FFI is *not* preempted by this contract.

**Authority and lifecycle:** a continuation is per actor incarnation; a stale nonzero generation cannot regain authority after CLOSED or new generation. Status transitions: EMPTY → SUSPENDED/RUNNING → DONE → CLOSED; RUNNING is not callable reentrantly. A suspended continuation remains one in-flight accepted DATA turn, not a new mailbox message. STOP drains already accepted work. PANIC fences all new DATA and resumed continuations and waits for physical quiescence before freeing frame storage. CONTROL remains strict priority before starting new DATA. A compiler may emit a single active frame per isolated actor worker as its first implementation; such a result is **single-frame backend support only**, not multi-actor or pooled-runtime parity.

**Terminal fault handling (M8 audit amendment):** A checked arithmetic failure must first persist `FAILED` (distinct from the physically executing `RUNNING` state), together with a stable fault reason, before a Wasm/native trap is raised. The accepted turn is not DONE and must not resume or replay its previously committed mutations. The host may inspect the fault, then explicitly close a physically quiescent FAILED frame. CLOSE zeroes live scalar state and the fault; subsequent new-frame admission increments the generation and invalidates every old handle. The initial restricted Wasm profile uses fault codes 0=none, 1=checked add overflow, 2=checked index increment overflow. These codes do **not** by themselves constitute a supervisor PANIC CONTROL notice; notification and delivery remain a separate host integration requirement.

**Ownership:** v1 supports only owned signed integers. Borrow/critical-state loans at any suspension boundary must be rejected, not silently serialized, copied, or pinned. Compilers must reject unsupported effects/commands at compile time without generating an executable guest.

**Evidence:** for each backend report independently (i) exact source SHA/tree, (ii) real compiler executable, (iii) real guest execution with 1/4/65536 reduction slices, (iv) checked arithmetic overflow, (v) stale/fabricated continuation handles and (vi) existing M7 CONTROL conservation. An ABI shape test or a standalone Java code generator alone is not a canonical compiler acceptance receipt. Rust/Wasm browser emits an `atto.m8.cooperate` restricted, separate guest export profile; it is not the normal `atto.browser.guest.v2` actor process API until integrated with the host scheduling/messaging contract.
