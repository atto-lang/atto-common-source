**10 passing observations, 2 real gaps; overall gate exits 1.** A backend rejecting
a valid positive example does not count as parity. The .NET import diagnostic
is the first observed blocker; class/string support remains unproven by this
case until import admission succeeds.

Foo's exact stdout bytes were `hello world\nhiiii 2hiiii` with no trailing newline.
Both scalar controls produced empty stdout and returned 0.

The initial harness redirected native stdout to a regular file. The strict-NIO
console correctly refused that destination, so that run is superseded. The
committed runner uses concurrently drained pipes and persists the bytes afterward.
This required a harness correction, not a compiler/runtime change or guest rewrite.

The local evidence directory is `outputs/three-backend-corpus-run-20261110-final`
in the engineering workspace. It retains source snapshots and hashes, compiler
commit/tree identities, build/dependency hashes, commands, statuses, diagnostics,
LLVM IR, linked binaries and exact output. Selected raw observations accompany
this document under `evidence-20261110/`; large build products remain local.

Next work stays sequential: consolidate the tested integration branches, then
close ordinary source gaps, beginning with .NET `routine` and `.atto` imports.
Passing this baseline will still not establish actors, HTTP, ownership or Spin
server parity; those require additional executable cases and full server tests.
